# aseprite-agent (bridge)

MCP server that lets [Claude Code](https://claude.com/claude-code) or [Codex CLI](https://github.com/openai/codex) control a running Aseprite, and runs the in-app chat panel's agent.

It needs the **Aseprite Agent extension** installed in Aseprite. See the [project README](https://github.com/codeyoma/aseprite/tree/agent/agent) for setup, tools and demos.

```bash
claude mcp add aseprite -- npx -y aseprite-agent
```
